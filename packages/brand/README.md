# @lavagna/brand

Source files for the Lavagna identity and the exports derived from them.

```
src/        editable sources (SVG)
fonts/      vendored Inter, a build input (see fonts/README.md)
exports/    generated by build.mjs — never edit by hand
build.mjs   regenerates exports/ from src/
```

`exports/` is the single source of truth for both consumers, and neither copies
by hand:

- **The extension** copies at build time. `apps/extension/esbuild.js` writes
  `exports/icon-256.png` → `media/icon.png` and `exports/activity-bar.svg` →
  `media/spiral.svg`; both destinations are gitignored, exactly as
  `apps/extension/skills/` is. `@lavagna/brand` is a `workspace:*`
  devDependency of the extension so Turbo builds this package first — nothing is
  imported from it at runtime. `vsce package` runs `vscode:prepublish` → build,
  so the files exist by the time the `.vsix` is assembled.
- **The website** cannot: GitHub Pages serves `docs/` straight from git, so
  `docs/assets/` has to hold committed copies. `scripts/check-brand-sync.mjs`
  compares them byte for byte and fails if they drift; it runs in `pnpm check`
  (as the Turbo root task `//#check-brand`) and in CI.

## The mark

The logo is the spiral `꩜` — U+AA5C CHAM PUNCTUATION SPIRAL. *Lavagna* is
Italian for blackboard; the icon is a chalk spiral on a slate tile.

The outline is the glyph from **Noto Sans Cham** (Google, SIL Open Font
License 1.1). Glyph outlines used as artwork are not Font Software under the
OFL, so this logo carries no OFL obligations; the Reserved Font Name "Noto"
is not used for it. The licence text is committed as `OFL.txt` next to the
extracted outline, since that file *is* a redistributed piece of the Font
Software. Provenance:

- `src/spiral-glyph.raw.svg` — the outline exactly as extracted from the font
  (font units, y-up, `transform="scale(1,-1)"`). Kept for reference only;
  covered by `OFL.txt`.
- `src/mark.svg` — the same outline, cleaned: the y-flip baked into the
  coordinates, scaled so the glyph's width spans the `0 0 1000 1000` viewBox,
  centred, coordinates rounded to one decimal. The shape is untouched.

Do not redraw the mark, and do not paste its path anywhere. `src/mark.svg` holds
the only copy; every other source carries a `{{MARK_PATH}}` placeholder that
`build.mjs` substitutes, and the build fails if a source has lost it. Those
sources therefore show the tile but no spiral when opened directly — that is the
trade for not having four copies to keep in step.

## Files

| File | What it is |
| --- | --- |
| `src/mark.svg` | The glyph alone, `fill="currentColor"`, square viewBox, centred. Use on any background. The one copy of the outline. |
| `src/icon.svg` | Slate rounded square (radius 22% of the side) with the mark in chalk at 65% of the side. A 10%-opacity chalk hairline runs inside the edge so the tile separates from dark marketplace backgrounds. |
| `src/icon-fullbleed.svg` | `icon.svg` with square corners and no hairline, for the iOS home-screen tile. |
| `src/wordmark.svg` | "Lavagna" as live `<text>`: `Inter, -apple-system, Segoe UI, Helvetica, Arial, sans-serif`, weight 600, letter-spacing 0.01em. |
| `src/lockup.svg` | Mark + wordmark side by side, `currentColor`. |
| `src/og-image.svg` | 1200×630 social card: slate ground, lockup, tagline in chalk at 72% opacity. |
| `fonts/` | Inter (OFL 1.1), vendored — see `fonts/README.md`. Build input only; nothing ships it. |
| `exports/icon-{128,256,512}.png` | Marketplace icon (the Marketplace wants PNG, ≥128px; the extension ships 256). |
| `exports/favicon.svg` | `icon.svg` with the mark path substituted in. |
| `exports/favicon-16.png`, `favicon-32.png`, `favicon.ico` | Legacy favicons; the `.ico` holds both PNGs (PNG-in-ICO). |
| `exports/apple-touch-icon.png` | 180×180, full-bleed slate from `icon-fullbleed.svg` (iOS applies its own corner mask). |
| `exports/og-image.png` | The social card rendered. |
| `exports/activity-bar.svg` | 24×24 monochrome mark for the VS Code activity bar (`fill="currentColor"`, single path). The glyph is fitted into a 20-unit box; its quadratics are transformed, not flattened. |
| `exports/CHECKSUMS.txt` | sha256 of every other export, generated. `cd exports && sha256sum -c CHECKSUMS.txt`. |

**Text is live, but the layout is not left to chance.** `wordmark.svg`,
`lockup.svg` and `og-image.svg` use `<text>` in an Inter/system-sans stack, so
the letterforms follow whatever the viewer has. Every string carries a
`textLength` with `lengthAdjust="spacingAndGlyphs"`, so a different face changes
the shapes but never the width — the wordmark cannot overrun the card. And
`build.mjs` rasterises only with the Inter in `fonts/` (`loadSystemFonts:
false`), so `og-image.png` is the same bytes on Linux, macOS and Windows.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| **Slate** | `#22272b` | Icon tile, website background, `galleryBanner.color`. |
| **Chalk** | `#f2efe9` | The mark and text on slate. |
| **Ochre** (accent) | `#dcaa4f` | Links and highlights on slate. |

Contrast (WCAG 2.x relative luminance):

| Pair | Ratio | |
| --- | --- | --- |
| Chalk on slate | 13.1 : 1 | AAA |
| Ochre on slate | 7.1 : 1 | AAA normal text |
| Ochre on `#1e1e1e` | 7.9 : 1 | AAA |
| Ochre on white | 2.1 : 1 | fails — the accent is for dark grounds only; on white use slate for text |
| Slate on white | 15.1 : 1 | AAA |

## Regenerating

```sh
pnpm --filter @lavagna/brand run build
```

Requires `@resvg/resvg-js` (a devDependency, pinned exactly, installed with the
workspace). The build reads only `src/`, `fonts/` and its own script — no
network, no shell, no system fonts — and is deterministic on every platform: run
it twice and `git status` stays clean. `exports/CHECKSUMS.txt` records what the
current sources produce, so a diff in `exports/` can be told from a mistake.

The extension picks the change up on its next build. The website's copies are
the one manual step, because they are served from git:

```
exports/favicon.svg, favicon.ico, apple-touch-icon.png, og-image.png → docs/assets/
```
